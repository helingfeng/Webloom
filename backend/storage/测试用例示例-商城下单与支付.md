# 商城下单与支付需求

> 覆盖从加入购物车到支付完成的核心链路。

### 首页加载冒烟
- 打开商城首页
预期结果：页面正常渲染，无报错

## 购物车模块

### 加入购物车
前置条件：用户已登录
- 进入商品详情页
- 选择规格
- 点击「加入购物车」
预期结果：购物车数量 +1，提示「已加入购物车」

### 修改购物车数量
前提：购物车中已存在该商品
1. 进入购物车页面
2. 点击数量「+」
期望结果：数量增加，小计金额同步更新

### 删除购物车商品
前置条件：购物车中存在该商品
- 点击「删除」
- 确认删除
预期结果：商品从列表移除，总价重新计算

## 结算与支付模块

### 正常下单支付
前置条件：购物车至少一件商品，且已配置收货地址
- 点击「去结算」
- 选择收货地址与支付方式
- 点击「提交订单」
- 在收银台完成支付
预期结果：订单状态变为「已支付」，库存扣减，跳转支付成功页

### 库存不足下单
前提：商品库存为 0
- 将该商品加入购物车后进入结算
期望结果：提交订单时提示「库存不足」，无法支付

### 支付超时自动取消
前置条件：已提交订单但未支付
- 等待超过支付时限
预期结果：订单自动取消，库存回滚

## 优惠券模块

### 使用满减券
前置条件：账户持有可用满减券，且订单金额满足门槛
- 在结算页选择满减券
- 提交订单
预期结果：实付金额 = 订单金额 − 优惠金额

### 优惠券不满足门槛
前提：订单金额低于券使用门槛
- 尝试选择该券
期望结果：券置灰不可选，提示「未达使用门槛」
